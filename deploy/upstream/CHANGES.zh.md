# PowerEvolve 上游同步变化

[English](CHANGES.md) | 中文

本页说明当前源码的变化。新环境安装、smoke9 和既有会话真实续聊仍需完成验收。

- 冷账号会在模型首个步骤捕获工具前恢复已保存的启用 MCP 连接，无需先打开 MCP 设置页。不同账号继续使用各自的工具与凭据。
- 云端准入的 Node 流在通用内部故障时显示固定公开文本，错误帧不带服务器路径与私密诊断。其他 Remote 错误代码保留原消息，原传输继续持有清理责任。
- PowerEvolve 名称、图标、运行提示、新会话入口、自有插件与技能页面，以及每账号自己的模型/搜索密钥管理入口继续保留。

本轮撤回无人调用的原生辅助函数及标记异常，不再额外宣称认证每次宿主只读取消和句柄物理关闭；对应的分支专用测试随辅助函数退役。会话读取采用原生实现，账号鉴权、输出前核验和实际写入责任仍由云端承担。退役要求不计为测试通过。

原生会话格式常量为 **4**，原生 SQLite 结构常量为 **1**；此前比较基准与本次原生目标均为这两个值，本轮不追加版本递增。版本常量相同不能代替既有会话真实续聊验收。

逐文件处置见[台账](ledger.tsv)，源码生成的接口清单见[SEAMS.md](SEAMS.md)。

等您回来看的事：目前技能名额只做了过渡：每个账号只有两个工作区能挂技能，第三个工作区可以执行命令但不能用技能；释放闲置工作区占用名额的真正回收还没做。
