# PowerEvolve cloud Workspaces client

English | [中文](README.zh.md)

This product plugin adds owned cloud Workspace selection and creation to the native DSH Web shell. A Session binds its Workspace when created; switching the visible project never changes an existing Session's Workspace. The trusted platform verifies ownership and stores the Workspace and Session records. The plugin does not access the shared POSIX root.

See [S2 interfaces](../S2-INTERFACES.md) and the [S2 trial](../TRIAL-S2-NATIVE.md).
