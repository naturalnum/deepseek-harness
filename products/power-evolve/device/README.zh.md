# 本机设备 Bundle

[English](README.md) | 中文

这个独立 `dsh` Bundle 启动仅在本机开放的授权页面和已配对设备执行器。当前 OS 用户授权项目目录；绝对路径和设备令牌留在本机私密状态中。命令在只挂载一个授权目录的临时 Docker 容器中运行。云端文件传输需要在设备页面明确操作。

macOS/Linux 使用上游原生 `flock`，阻止另一 Worker 同时使用同一私有根目录。Journal 在清理之前保存已受理请求的摘要、创建者身份、不可变镜像／容器 ID 和观察到的停止状态。冷恢复不会创建或启动替代命令；身份缺失及旧 Journal 需要核查，并阻止新命令准入。实例缺失不能单独作为停止观察。平台固定原命令与超时，将独立 Worker 进程绑定到派发，并在精确容器登记后只发放一次启动许可。领取前先将原进程与排队输入写入 Journal。领取回执丢失时，同一存活进程可以重试；冷恢复 `claiming` 使用下述未获启动权限的封存流程。登记回执丢失不会授权第二次启动。停止报告保留原进程／派发与稳定重试 ID；匹配的持久终态回执才允许本地清理。已撤销凭据只能清理既有任务，不能获取新任务。副作用结果不明时，PG 保留占用且不自动续接。

严格的冷 `claiming` 记录保留固定排队输入及原进程，没有已领取派发、镜像、容器、停止或结果事实。Worker 持有私有 Journal 与共享写入锁，由平台永久封存原领取。平台核验固定身份与不存在启动权限，拒绝后续 claim/register/finish，持久保存唯一回执并至多一次续接；停用账户不产生新续接。Worker 在请求前同步稳定封存 ID，在退掉原未登记写入槽前同步匹配回执，再删除 Journal 项。回执丢失和中断清理重试同一封存，不重建旧占用或清除其他写者。这里记录的是永久禁止原启动的事实，不是 Docker 停止或命令结果；`claimed`／`created` 不进入此流程。

平台 `/devices/agent/registered` 接口接受原登记字段，只查询已有的匹配容器登记。响应始终为 `canStart:false`；缺少登记、归属变化或执行已永久封存时拒绝，且不修改记录。恢复通过此查询核验既有登记，与正常首次登记的启动授权分开。

平台通过独立审批核验原请求、登记、进程、派发、精确容器和停止记录摘要后，才可将已停止但结果不明的执行结案为 `closed_unknown`。结案保留原输出与停止事实，在原会话至多排队一次续接。结案或撤销后，Device 仍可重试相同停止报告；回执允许清理，不授予新的启动权限。`claimed`／`created` 缺少停止事实和旧身份不全时继续受阻。原生执行区域只展示事实，并链接到已有独立审批台。

同一 OS 用户的所有协作 Device Profile 使用同一个配置的 `coordinationRoot`，与各自私有 Journal 分开。一个持久写入槽串行处理命令与显式传输，也涵盖互不相关或重叠的项目目录。命令意图先于 Platform 领取和 Docker 创建；进程停止或丢失不会清除结果未知的任务。已登记槽在精确容器移除、且收到匹配的已知结果或独立结案停止回执后，才清除占用；未登记的冷领取使用上述永久禁止原启动的封存流程。持久 `waiting` 尚未提交领取，重启后可继续。这种保守串行方式不隔离其他 OS 应用或不同 OS 用户。改变协调根前必须停止既有写者并对账其记录。

显式本地授权记录物理根目录的十进制 dev/ino 身份。旧授权需要本地重新确认；物理目录替换需要新授权。传输的有界 Python helper 继承并保留共享内核锁描述符，父进程死亡后仍持有。描述符相对遍历拒绝符号链接及非普通文件；读取限制为 2 MiB，导入只创建、不覆盖。导入响应中断时目标可能已提交，应先检查再重试。Cloud 获得目录 ID 和标签，不获得本机路径；根目录、Home 以及重叠的私有／协调目录不能授权。

[Bundle 配置](cordis.patch.yml)明确共享协调根、Python 可执行程序、文件操作期限、轮询、失联、平台／Docker 请求及选择器超时，以及 Docker 停止宽限期。macOS/Linux 需要 Python 3.9 或更高版本。关闭时停止准入，等待 helper 实际退出、本地操作及有界命令停止尝试，然后分别尝试释放写入锁和 Journal 锁；未确认停止的 Docker 写者继续保留记录。平台也阻止不同会话在同一 Device／目录授权内并发运行命令。完整桌面恢复与 Electron 交付由[桌面补齐约定](../DESKTOP-COMPLETION.md)定义。插件未激活时，Device readiness 与 WebServer 可访问是不同状态。

按照[切片 5 试用指南](../TRIAL-SLICE5.md)配对设备并测试云端和桌面执行。Web 服务必须绑定本机回环地址。此 Bundle 不包含云宿主的 Agent 循环或平台数据库凭据。
