# 本机设备 Bundle

[English](README.md) | 中文

这个独立 `dsh` Bundle 启动仅在本机开放的授权页面和已配对设备执行器。当前 OS 用户授权项目目录；绝对路径和设备令牌留在本机私密状态中。命令在只挂载一个授权目录的临时 Docker 容器中运行。云端文件传输需要在设备页面明确操作。

macOS/Linux 使用上游原生 `flock`，阻止另一 Worker 同时使用同一私有根目录。Journal 在清理之前保存已受理请求的摘要、创建者身份、不可变镜像／容器 ID 和观察到的停止状态。冷恢复不会创建或启动替代命令；身份缺失及旧 Journal 需要核查，并阻止新命令准入。实例缺失不能单独作为停止观察。平台终态回执必须指向原执行，才允许清理 Journal。

[Bundle 配置](cordis.patch.yml)明确轮询、失联、平台／Docker 请求及选择器超时，以及 Docker 停止宽限期。关闭时停止准入，等待本地操作及有界命令停止尝试，再释放 Journal 锁；未确认停止的 Docker 写者继续保留记录。这把锁不协调不同私有根、重叠目录或其他 OS 应用。完整桌面恢复切片仍需平台停止回执、目录写者预留及本地目录描述符相对访问，见[桌面补齐约定](../DESKTOP-COMPLETION.md)。插件未激活时，Device readiness 与 WebServer 可访问是不同状态。

按照[切片 5 试用指南](../TRIAL-SLICE5.md)配对设备并测试云端和桌面执行。Web 服务必须绑定本机回环地址。此 Bundle 不包含云宿主的 Agent 循环或平台数据库凭据。
