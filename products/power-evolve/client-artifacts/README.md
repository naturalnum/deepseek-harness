# PowerEvolve artifacts client

This product plugin adds explicit publication from the current Session's Workspace and an artifact tab to the native DSH right sidebar. Publication creates an immutable platform-owned copy with metadata in PostgreSQL; later edits to the source file do not change the published artifact. Preview and download use the trusted platform's per-user authorization checks.

See [S2 interfaces](../S2-INTERFACES.md) and the [S2 trial](../TRIAL-S2-NATIVE.md).
