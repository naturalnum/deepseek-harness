# PowerEvolve 扩展中心

[English](README.md) | 中文

原生 DSH Web 侧栏装配按用户隔离的“技能”和“插件”页。技能页提供“我的技能”和“全部技能”、分类搜索，以及由平台提供的九项固定内置技能目录。目录安装在结果不确定时沿用同一请求编号，成功后更新“我的技能”。技能页也支持列出、读取、安装、启停和撤销个人文本技能与 ZIP 技能包。已安装技能的说明可直接预览，无需启动沙盒。同源 Host RPC 签发短时上传票据，浏览器把技能包字节直传平台，Host 不缓冲 ZIP。版本、摘要和就绪状态均以平台响应为准。“试用技能”在新的原生会话中填入可编辑的原生调用草稿，调用名沿用 Host 的稳定别名，界面仍显示原名称；用户发送任务后，代码仅在获授权的云沙盒中运行。插件页展示平台持有的受控便签状态，使用稳定请求编号修改个人启用状态，并链接至独立的可信审批页。原有固定 MCP 页可为每位用户安装一份由运营方固定的只读 whoami 连接、启停并查看有界测试结果，不接受服务地址、请求头或凭据输入。个人 SSH 页支持列出服务器、凭密码和经独立核对的主机密钥指纹创建连接，以及启停连接。浏览器凭短时票据把最多 4096 字节的 UTF-8 密码直传到可信平台的固定上传地址；Host 只收到元数据和字节数。SSH 凭据检查只验证登录，不执行远程命令。最近检查列表可在浏览器刷新后恢复当前账号的调用状态，并用一次有界列表 RPC 轮询未结束的调用。Agent 可以针对已固定的 SSH 连接提议一条确切命令；可信平台在独立审批页展示命令和目标，供用户确认。只有获批准的命令才会经专用 Runner 执行，有界结果将续接到原会话；拒绝不会创建 Runner 调用，执行请求也可以取消。私钥认证、连接编辑与删除仍不可用。

Remote MCP 插件打开原版多连接页，提供搜索、详情、创建/编辑弹窗、启停、删除、只写 Bearer 和自定义请求头字段，以及已保存配置/草稿检查、取消与持久状态展示。浏览器适配器通过同源 MCP 管理 RPC 发送元数据，并凭短时票据把替换凭据直传可信平台的固定上传地址。Host 只收到名称、操作和字节数，不接收凭据值。上传响应丢失后，客户端查询原请求回执。显式重试沿用同一请求编号与不可变输入。

检查使用已有原生会话，默认选择主视图保留的会话。检查未结束时，所选会话保持固定；删除该会话会使草稿检查失效，迟到响应不能覆盖已修改草稿或已取消检查。连接身份、配置和凭据版本用于识别过期的正式检查结果。旧结果作为历史保留，当前配置明确显示尚未检查。草稿检查使用独立版本，不代表保存后的配置已通过检查。启停会增加连接修订，不改变配置版本。页面持续展示到期和取消结果。只有等待或运行中的检查已请求取消时，才显示取消中的提示；即使保留了取消请求标记，终态检查也会隐藏该提示。管理服务不可用时禁止写入，但允许刷新。原有固定 MCP 卡片保留独立记录和 API。

定向客户端测试使用明确标注的网络和 Port 替身，以及本模块的列表渲染快照，验证浏览器传输、凭据脱敏、页面行为和原生会话选择。这些测试不代表真实平台联调或双用户隔离验收。
