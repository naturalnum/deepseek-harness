# PowerEvolve 扩展中心

[English](README.md) | 中文

原生 DSH Web 侧栏装配按用户隔离的“技能”和“插件”页。技能页支持列出、读取、安装、启停和撤销个人文本技能与 ZIP 技能包。同源 Host RPC 签发短时上传票据，浏览器把技能包字节直传平台，Host 不缓冲 ZIP。版本、摘要和就绪状态均以平台响应为准。“试用技能”在新的原生会话中填入可编辑草稿；用户发送任务后，代码仅在获授权的云沙盒中运行。插件页展示平台持有的受控便签状态，使用稳定请求编号修改个人启用状态，并链接至独立的可信审批页。个人 MCP 页可为每位用户安装一份由运营方固定的只读 whoami 连接、启停并查看有界测试结果，不接受服务地址、请求头或凭据输入。个人 SSH 页支持列出服务器、凭密码和经独立核对的主机密钥指纹创建连接，以及启停连接。浏览器凭短时票据把 UTF-8 密码字节直传到可信平台的固定上传地址；Host 只收到元数据和字节数。SSH 凭据检查只验证登录，不执行远程命令。最近检查列表可在浏览器刷新后恢复当前账号的调用状态，并用一次有界列表 RPC 轮询未结束的调用。远程命令执行、私钥认证、编辑与删除仍不可用，需等 [S6 切片](../DELIVERY-PLAN.md)中的云端适配完成。
