# PowerEvolve Extension Center

English | [中文](README.zh.md)

The native DSH Web sidebar hosts per-user Skills and Plugins pages. Skills lists, reads, installs, enables, disables, and revokes personal text skills and ZIP packages. The same-origin Host RPC issues a short-lived upload ticket; the browser sends package bytes directly to the Platform, and the Host never buffers the ZIP. Package versions, digests, and readiness come from the Platform. “Try skill” opens an editable draft in a new native Conversation; the user sends the task, and any code runs only in an authorized cloud Sandbox. Plugins displays the Platform-owned controlled notes status, changes its personal enablement with a stable request ID, and links to the separate trusted approval page. The personal MCP page installs one operator-fixed read-only whoami connection per user, toggles it, and displays a bounded test result. It accepts no endpoint, header, or credential input. The personal SSH page lists servers, creates password-based connections with an independently verified host-key fingerprint, and changes enablement. The browser sends UTF-8 password bytes directly to the trusted Platform's pinned upload endpoint using a short-lived ticket; the Host receives only metadata and the byte count. SSH connection checks, execution, private-key authentication, edits, and deletion remain unavailable until their cloud adapters are delivered in the [S6 slice](../DELIVERY-PLAN.md).
