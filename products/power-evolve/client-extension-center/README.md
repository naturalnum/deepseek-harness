# PowerEvolve Extension Center

English | [中文](README.zh.md)

The native DSH Web sidebar hosts the per-user Skills page. It lists, reads, installs, enables, disables, and revokes personal text skills and ZIP skill packages. The same-origin Host RPC issues a short-lived upload ticket; the browser sends package bytes directly to the Platform, and the Host never buffers the ZIP. Package versions, digests, and readiness come from the Platform. “Try skill” opens an editable draft in a new native Conversation; the user sends the task, and any code runs only in an authorized cloud Sandbox. The Plugins page belongs to the later [delivery slice](../DELIVERY-PLAN.md).
