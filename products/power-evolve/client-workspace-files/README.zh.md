# 原生工作区文件

[English](README.md) | 中文

此产品客户端通过原生 DSH 输入区、文档预览和 Files 标签页提供获授权的上传、编辑与下载操作。[应用服务](../application/README.zh.md)负责身份核验和存储访问。

上传使用当前输入区的 Session ID，由 Platform 实时核验归属。工作区目录列表更新延迟不会阻止上传；Platform 拒绝时显示上传失败，不添加附件引用。

文件选择属于正在查看的 Session、标签页和根目录。隐藏标签页保留选择；关闭标签页清理选择并取消准备。单文件下载原始字节，多文件下载保留相对目录的 ZIP。浏览器负责传输进度和取消；准备失败保留选择，允许重试。[S2 文件补齐](../S2-COMPLETION.md)定义限额及验收范围。

客户端包包含共享下载字段验证，并关闭 Zod JIT 以满足页面 CSP。控件使用原生 Files 行前和工具栏插槽，不另建文件树或执行环境。选择状态由单个存储持有，无需独立的运行时不变量安装器。
