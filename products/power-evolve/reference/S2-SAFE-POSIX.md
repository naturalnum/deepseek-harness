# S2 POSIX workspace access

`FileService` uses `application/src/platform/safe-posix.py` for workspace file operations on macOS and Linux. The platform host needs Python 3.9 or newer on `PATH`, and the `.py` file must be deployed alongside the application source and compiled `lib`. `FileService.init()` probes both at startup and fails closed if either is missing. Python runs with `-I -B`, a fixed minimal environment, no shell, and a 10 second deadline per operation.

Node has no portable `openat`/`renameat` API. The helper opens the canonical absolute workspace root one directory component at a time, then keeps directory descriptors while resolving the authorized workspace and each user path component with `O_DIRECTORY | O_NOFOLLOW`. It reads regular files through `O_NOFOLLOW` descriptors, lists an open directory descriptor, and performs revision comparison, temporary creation, `os.replace`, and `fsync` relative to one retained parent descriptor. A renamed or symlinked intermediate path cannot redirect the operation into another tree. Authentication, workspace ownership, mutation idempotency and mount-slot exclusion remain in PostgreSQL and `FileService`.

Each call starts a fresh Python process. Input and output are limited to 4 MiB each; file data is base64 encoded in the JSON message, with a 2 MiB decoded file limit. At most eight helpers run concurrently per `FileService` instance. The process receives no model keys or bearer tokens. On the S2 macOS development host, 256 adversarial single-process operations took about 21 seconds (roughly 80 ms each); one ordinary `FileService` operation starts one helper. A timeout, malformed response, or saturated helper limit returns `workspace_unavailable` (503). If a write times out after its filesystem rename but before the PostgreSQL commit, retrying the same request and bytes follows the existing digest recovery rule.

Artifact publication reads source bytes through `FileService.readInWorkspace`, so it inherits descriptor-relative containment. Artifact snapshots live in a separate platform-private directory that is never mounted into a Sandbox. Before deployment, run `s2-safe-posix.test.mjs` and `s2-workspaces.test.mjs` on the target OS. The helper was exercised on macOS Python 3.12 and Linux Python 3.11.
