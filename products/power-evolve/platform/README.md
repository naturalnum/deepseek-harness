# Trusted platform bundle

English | [中文](README.zh.md)

This standalone `dsh` bundle composes the web server and PowerEvolve [trusted platform](../application/README.md#trusted-platform). It owns the database connection, identity checks, durable operations and credentialed model requests. It does not run Agents.

Use the [trial guide](../TRIAL.md) to prepare its private configuration. Schema initialization and test-account seeding finish before readiness is published. Existing accounts are not overwritten by a restart.
