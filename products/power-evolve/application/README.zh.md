# PowerEvolve 应用插件

[English](README.md) | 中文

这个私有包提供两个独立启动的应用。宿主 Bundle 加载 `scope`、`persistence`、`model` 和 `host`，平台 Bundle 加载 `platform`。共用包不代表共用进程、数据库连接或模型凭据。

<a id="host"></a>
## 宿主

`scope` 调用指定的平台端点，按原生 Session 身份保存执行授权。`persistence` 为获得租约的根会话实现原生 Session 存储服务；经过身份验证的会话创建由平台 API 负责。未获租约的访问、分叉和任意原生创建会被拒绝。非活跃历史保存在 PostgreSQL。每个操作恢复一个 Agent，持久完成后将其释放。

`model` 使用原生 DeepSeek Messages 编解码器。它在推理前持久保存已消费输入和请求记录，然后向平台提交操作授权。`host` 通过经过身份验证的 JSON RPC 和有限额的 NDJSON 订阅，仅暴露产品 Typert 命名空间。描述符与平台共用请求校验器。此组合没有原生操作者级全局配置、任意文件系统访问、进程工具、插件安装和执行路由。

<a id="trusted-platform"></a>
## 可信平台

身份模块验证预置测试账号，签发有期限的不透明 Agent 令牌，并在退出时撤销。会话 API 从经过验证的身份确定资源归属。任务准入、请求去重、用户容量、领取和租约代次在 PostgreSQL 事务中提交。事件追加需要当前授权，重复记录必须完全一致。模型出口验证授权、模型及输出额度，并注入真实模型密钥。平台还拥有每个用户的 POSIX 工作区和个人技能库。文件写入要求匹配原版本和请求 ID；任务受理时固定选用的技能版本。技能说明作为数据进入该用户 Agent 的提示词，代码不会装载到共享宿主。

配置在两个 Bundle 补丁中显式声明。必需的秘密值在启动时从私密文件读取。数据库连接池、超时、请求/历史/输出限制、用户准入、宿主并发、轮询、租约续期和订阅上限均可配置。就绪文件记录所属进程实例，供试用生命周期脚本核验。

## 恢复与限制

操作提交后，客户端才收到 `accepted`。未消费的输入可以在重启后投递。已消费但没有完成轮次的输入由原生 DSH 恢复逻辑补齐中断记录，并报告失败，不会自动再次发送给模型。完成响应丢失时，重新领取租约后根据已保存的轮次核对结果。

本切片支持根会话文本对话、有限大小的文件传输和文本编辑，以及个人技能说明。完成的输出通过持久事件订阅传送，部分模型 token 不广播到浏览器。私有 Profile 不承诺兼容所有原生 Controller 或 Session 存储消费者。它拒绝未知 Session 版本，不迁移旧 PowerEvolve 数据库。工具注册表为空，本切片没有待恢复的 Agent 执行副作用。

本机试用在当前 OS 用户下运行独立进程。这不能在进程失守时提供文件系统或网络隔离。生产部署接入不可信租户之前，必须为宿主和平台配置独立身份、密钥挂载与网络策略。可写沙盒挂载还需要更强的路径隔离。审批、连接器、沙盒、桌面设备及生产入口属于后续切片。

## 验证

`pnpm run test:power-evolve` 使用构建后的 `dsh` Profile、真实且唯一命名的测试数据库，以及确定性 Messages 端点。测试覆盖身份和配置区分、授权拒绝、订阅、重复受理、中断/重启、旧授权、退出、原生历史回放、Agent/Session 回收、文件字节与访问边界，以及个人技能选择。测试监听端口由 OS 分配，清理时等待子进程退出和数据库连接关闭。本机浏览器试用另行验证真实 DeepSeek 调用。
