# PowerEvolve 应用插件

[English](README.md) | 中文

这个私有包提供三个独立启动的应用。宿主 Bundle 加载 `scope`、`persistence`、`model` 和 `host`，平台 Bundle 加载 `platform`，本机设备 Bundle 加载 `device`。共用包不代表共用进程、数据库连接或模型凭据。

<a id="host"></a>
## 宿主

`scope` 调用指定的平台端点，按原生 Session 身份保存执行授权。`persistence` 为获得租约的根会话实现原生 Session 存储服务；经过身份验证的会话创建由平台 API 负责。未获租约的访问、分叉和任意原生创建会被拒绝。非活跃历史保存在 PostgreSQL。每个操作恢复一个 Agent，持久完成后将其释放。

`model` 使用原生 DeepSeek Messages 编解码器。它在推理前持久保存已消费输入和请求记录，然后向平台提交操作授权。`host` 通过经过身份验证的 JSON RPC 和有限额的 NDJSON 订阅，仅暴露产品 Typert 命名空间。按 Agent 装载的原生工具提供受控便签查询、审批申请，以及按本次选择的云端或桌面目标提交命令的回执。此组合没有原生操作者级全局配置、任意文件系统访问、进程工具、插件安装和执行路由。

原生 Web 的登录页可把仅保存在内存中的 Agent 凭据 POST 到宿主 `/auth/exchange`。平台原子地注销这枚凭据，并签发保留原过期时间的新凭据；宿主将新凭据写入只发往 `/native/api` 和 `/api/powerEvolve` 的 HttpOnly、SameSite=Strict Cookie。URL 和浏览器存储不包含凭据。适配器对每次产品 RPC、事件流和 WebSocket 升级调用 `powerEvolveBrowserAuth.authenticate(request)`；Cookie 请求必须来自配置的宿主 Origin，交换请求必须来自配置的平台 Origin。平台仍负责校验到期和注销。除本机回环地址外必须使用 HTTPS。原生传输层在 `/native/api` 提供受限的会话列表、创建、文本输入、取消、历史分页、投影、订阅、控制和获授权的工作区订阅基线，也提供归属会话的文件列表、状态、文本、字节预览和变更订阅。浏览器看到的路径以 `/workspace` 为根；平台按每个已鉴权会话绑定的 POSIX 工作区解析路径，并逐次核验归属。WebSocket 复用上游 Gateway 的流复用器，平台调用仍按用户授权。其余原生端点返回错误，宿主不开放上游操作员接口。

<a id="trusted-platform"></a>
## 可信平台

身份模块验证预置测试账号，分别签发有期限的 Agent 和审批凭据，并在退出时撤销。会话 API 从经过验证的身份确定资源归属。任务准入、请求去重、用户容量、领取和租约代次在 PostgreSQL 事务中提交。事件追加需要当前授权，重复记录必须完全一致。模型出口验证授权、模型及输出额度，并注入真实模型密钥。每个用户有一个默认 POSIX 工作区，可通过 `/workspaces/create` 创建更多带标题的工作区；`/workspaces/list` 只返回本人的元数据。创建会话时永久绑定一个本人工作区，未指定 ID 则绑定原默认工作区。原平台 `/files` API 仍只访问默认工作区；原生读取和产品 `/files/session` 操作使用已鉴权会话绑定的工作区。文件写入要求匹配原版本和请求 ID；用户的可写云端挂载处于预留或活跃状态时拒绝平台直写。平台还拥有每个用户的个人技能库；任务受理时固定选用的技能版本。技能说明作为数据进入该用户 Agent 的提示词，代码不会装载到共享宿主。

发布产物时，平台把当前用户会话中不超过 2 MiB 的授权文件复制到沙盒不可见的私有目录，并在 PG 提交不可变元数据。稳定请求 ID 用于去重。列表、有界预览和校验后的字节下载逐次核验归属；之后修改工作区文件或回收沙盒不改变已发布产物。宿主允许同源安全 GET 使用限定路径的 Cookie 下载，向平台验证凭据并转发有界响应，不保存平台密钥。

连接器不启动执行沙盒即可查询受控 HTTP 便签 API。写入工具先在 PG 中持久保存准确的申请内容，并返回待审批回执，不能直接写入。平台域名下的独立页面展示原文和指纹。平台按当前身份核对归属和审批指纹，在派发前再次检查权限，并使用稳定的远端幂等键。结果不明时先查询，再决定是否重试。终态结果在原会话中排入一次平台消息；API 凭据只留在平台进程。

平台可以签发绑定用户、一次性使用的 SSH 凭据上传票据。浏览器只经宿主发送元数据和口令字节长度，再把有大小限制的 UTF-8 口令字节直接上传到平台域名。平台收到后计算摘要，按用户、连接和版本加密凭据；PG 不保存明文。独立 Connector Runner 和目的地策略尚未配置时，原生插件页不能开放安装。这条接收链路不会授权共享宿主或带可写工作区的编程沙盒运行 SSH 命令。

固定进程型 MCP 预设在原生插件页为每位用户提供带状态修订、仅本人可见的连接。任务受理时固定已启用的连接修订；原生 Agent 工具经共享宿主向可信平台提交稳定的工具调用 ID。平台先持久受理，再创建禁止网络出口且不挂载用户文件的短时 Connector Runner Pod，只启动镜像内置的只读 STDIO MCP 服务。终态或结果不明的调用在 PG 中保存，并向原会话排入一次消息。重新领取已提交的派发意图时，平台查询准确的 Pod UID、Runner 实例和调用摘要；状态缺失则标记不确定，不再 POST。宿主只接收连接元数据、回执和有界结果文本。此预设不接收用户命令、安装包或凭据。

执行服务仅在当前会话授权下受理命令，返回前先保存调用 ID。首次需要执行时，它为根会话创建一个 Agent Sandbox，只挂载该会话绑定的本人 POSIX 工作区和用户 Home；重试前先查询执行器状态。Home 仍为用户共享，因此每个用户只有一个 Kubernetes 物理资源槽位；前一个 Pod UID 的 kubelet 原生停止证据写入 PG 后，另一会话才可使用。新会话获得不同的 Pod UID、runner 身份和令牌。创建中断、缺少停止证据或租约过期均不能放行替代实例。终态结果在同一会话中排入平台消息，空闲回收保留 Git 文件和历史。Kubernetes 凭据只留在平台进程。

平台还保存设备身份、目录授权和本地命令状态。独立的本机设备 Profile 使用短期配对码接入，绝对路径和设备令牌只留在本机；命令在仅挂载一个获授权目录的临时 Docker 容器中执行。设备先记下命令身份，再创建容器，重启后核对容器状态。桌面与云端文件只通过明确的受限设备操作传输。

配置在三个 Bundle 补丁中显式声明。必需的秘密值在启动时从私密文件读取。私有产物根目录必须位于可写工作区根目录之外。工作区文件访问需要 Python 3.9+ 和随包部署的[目录描述符助手](../S2-SAFE-POSIX.md)；缺少时启动会拒绝就绪。数据库连接池、超时、请求/历史/输出限制、用户准入及工作区数量、宿主并发、轮询、租约续期和订阅上限均可配置。就绪文件记录所属进程实例，供试用生命周期脚本核验。

## 恢复与限制

操作提交后，客户端才收到 `accepted`。未消费的输入可以在重启后投递。已消费但没有完成轮次的输入由原生 DSH 恢复逻辑补齐中断记录，并报告失败，不会自动再次发送给模型。完成响应丢失时，重新领取租约后根据已保存的轮次核对结果。

取消会话时，平台在 PG 中核对当前用户的归属。尚未领取的输入直接以失败终结，不启动模型调用；运行中的输入保存取消意图，由持有租约的宿主在续租时读取。仍在运行的宿主取消 Agent，并在释放授权前保存原生日志。接替宿主不会重放已取消输入，后续仍可在同一会话提问。没有活跃操作时重复取消只返回成功，不改动历史。若轮次在宿主收到取消请求前已经结束，则以已记录的完成或失败结果为准。

本切片支持根会话文本对话、有限大小的文件传输和文本编辑、个人技能说明、两个受控远程 API 工具、云端命令及选定本地项目中的桌面命令。完成的输出通过持久事件订阅传送，部分模型 token 不广播到浏览器。私有 Profile 不承诺兼容所有原生 Controller 或 Session 存储消费者。它拒绝未知 Session 版本，不迁移旧 PowerEvolve 数据库。结果不明的远端写入或命令留在 PG 中等待对账；宿主不会盲目重放。

本机试用的宿主与平台进程仍使用当前 OS 用户，尚未按进程身份隔离。云端命令在按命名空间授权的 gVisor Agent Sandbox 中执行，本地命令使用配对设备上的 Docker。工作区文件已通过目录描述符相对访问抵御并发替换符号链接。生产部署接入不可信租户之前，还需要独立服务身份、网络出口规则、设备可信证明，以及多节点 POSIX 挂载验证。当前连接器是本机受控试用目标，并非通用第三方连接器目录。生产入口属于后续切片。

## 验证

`pnpm run test:power-evolve` 使用构建后的 `dsh` Profile、真实且唯一命名的测试数据库，以及确定性模型、远端 API 和沙盒执行器。测试覆盖身份和配置区分、授权拒绝、订阅、重复受理、中断/重启、旧授权、退出、原生历史回放、Agent/Session 回收、文件字节、个人技能、审批、远端对账、云端和设备执行、取消、实例变化及原会话续接。测试监听端口由 OS 分配，清理时等待子进程退出和数据库连接关闭。本机浏览器试用另行验证真实 DeepSeek、k3s 和已配对的本机设备。
