# 基础、关键问题或总体框架章节规则

本类章节只介绍后续技术章共同需要的对象、术语、变量、数据、平台、约束和评价口径。若不存在真正共用基础，不单独设置基础章。

章节仍执行统一技术章架构：一级章标题后直接写无标题章首导入正文，不设置“概述”“技术路线”或“技术架构”二级标题。章首导入先说明共同瓶颈及其对总体目标的影响，再概括共用对象、数据流、平台、变量关系和总体技术路线/架构，适合时配置图示。随后默认由X.1、X.2、X.3将真实基础单元归并为章内核心研究小点，必要时最小扩展为X.1—X.N，更多细节通过三级标题展开。以5万字全文为基准，章首导入正文目标约800—1200字。

技术定义应直接落到电网对象，例如节点、支路、设备、运行方式和调度周期。公式只有在统一状态、约束、映射或指标时使用，不能用空洞集合定义凑公式。
