# 图表使用规则

图表必须承担对象定义、路线说明、机制解释、实验比较或边界展示中的至少一种作用。技术路线图应包含输入、关键技术、反馈和输出；技术架构图应包含层次、模块、数据流/知识流/控制流和安全边界。

图表中的电力对象、符号、指标和单位与正文、公式一致。标记为实测的曲线和统计结果必须有 REAL_PROJECT_EVIDENCE。没有真实数据时，可以生成带内部模拟/示例来源状态的数据、结果表、预期趋势和绘图说明，用于帮助用户补做实验；但报告内容生成阶段仍不得实际绘制参考曲线、柱形图或示意图，所有插图位置继续使用白框占位。相关数据和表格可进入报告草稿；正文不要求每张表反复写“模拟/参考”，使用模拟数据的章节在章末统一说明一次，且不得冒充实测结果。

正文引用图表时先指出需要观察的位置，再解释结果及其电力含义，不逐项抄写表格。

## 正式报告中的插图占位硬规则

报告内容生成阶段不直接绘制或生成正式插图。凡正文需要技术路线图、总体架构图、流程图、数据流图、知识图谱示意图、实验结果图或其他插图时，统一在该位置放置**白色矩形边框占位框**，并在占位框下方保留正常图号和图题。

Markdown/章节内容中使用统一占位标记：

```text
【此处插入图2-1】
图2-1 迁移适配技术总体架构
```

占位标记必须位于对应图题正上方。最终Word排版子Skill负责把该标记确定性转换为白底、细边框、无文字的矩形图框；不得让大模型在框内生成示意内容、箭头、节点、文字或模拟曲线。正文仍应在图前后说明“该图应表达什么”和读图要点，以便用户后续补绘。

### 图表说明段与目录采集隔离

- 真正图题必须独占一段，格式为 `图X-X 图题`；真正表题必须独占一段，格式为 `表X-X 表题`。图号/表号与题名之间必须有明确空格。
- 只有上述真正图题、表题可以进入图目录/表目录。普通说明段不得以 `图X-X`、`表X-X` 起句，更不得写成 `图1-1应表达……`、`表2-1给出……` 这类容易被 Word 目录域误判的形式。
- 图前后说明优先写作 `该图应表达……`、`该图展示……`、`上述趋势表明……`；表格说明优先写作 `该表给出……`、`该表展示……`、`上述结果表明……`。需要指代具体图表时也先用“该图/该表”，不要重复用图号/表号起句。
- 图号/表号只承担正式图题、表题编号职责。正文中确需交叉引用时使用自然句式，例如“如图2-1所示”“由表2-1可知”，不得把整段说明写成疑似标题的编号开头。

若用户已经提供真实图片且明确要求直接插入，可由Word排版阶段替换对应白框；未明确要求时仍保留白框占位。
