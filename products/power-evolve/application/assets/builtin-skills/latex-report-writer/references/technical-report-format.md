# 中国电科院技术报告格式规范

本规范提取自用户提供的《技术报告格式.pdf》附录 B“技术报告格式”和附录 C“技术报告模板”。生成报告时以本文件为格式依据，以 [`../assets/report.docx`](../assets/report.docx) 为版式载体；两者不一致时，先按本文件修正模板和生成结果。用户已明确要求正文一级标题另起一页。

## 1. 报告构成

按以下顺序组织报告：

1. 封面
2. 审批页
3. 中文摘要、中文关键词、英文摘要、英文关键词
4. 目录
5. 正文
6. 附录（可选）
7. 参考文献（可选）

中文摘要至英文关键词排在同一页；当前 LaTeX 项目变体允许中英文摘要分别成页。附录置于正文之后、参考文献之前。

## 2. 页面设置

| 项目 | 要求 |
|---|---|
| 纸张 | A4，210mm x 297mm，纵向 |
| 上边距 | 30mm |
| 下边距 | 25mm |
| 左边距 | 25mm |
| 右边距 | 25mm |
| 页眉 | 可选；仅从正文第一页开始 |
| 页眉内容 | 技术报告中文名称，五号宋体，居中，与正文之间用下划线分隔 |
| 页眉位置 | 距上边界 25mm |
| 页脚位置 | 距下边界 15mm，无分隔线 |

封面至目录页不设置页眉。封面和审批页不设置页脚。

## 3. 页码与分节

- 中文摘要与关键词页开始设置页脚，使用小写罗马数字 `i, ii, iii...`。
- 目录延续前置部分的小写罗马数字页码。
- 正文第一页改用阿拉伯数字并从 `1` 重新编号。
- 正文、附录和参考文献使用连续的阿拉伯数字页码。
- 页码使用五号宋体，可居中或置于外侧；本 skill 统一采用居中。

## 4. 封面与审批页

封面按以下位置和样式排版：

| 内容 | 字体字号 |
|---|---|
| 报告编号、分类号、密级 | 五号黑体 |
| 项目来源 | 小三号黑体 |
| 中文报告名称 | 小二号黑体 |
| 英文报告名称 | 与模板保持一致，使用 Times New Roman |
| 系列报告名称及序号 | 小三号黑体 |
| 中国电力科学研究院有限公司 | 四号黑体 |
| 合作（协作）单位 | 四号黑体 |
| 报告发布日期 | 四号黑体 |

报告编号、分类号、密级三行位于封面右上方，使用同一个左起点左对齐；区块宽度按三行实际内容动态计算，最长一行（通常为报告编号）的最右字符贴齐右页边距内侧，即正文版心右边缘。
报告编写单位、合作（协作）单位和报告发布日期作为一个连续区块置于封面底部，并在正文宽度内居中。该区块使用封面正文层中的无边框浮动文本框，文本框底端固定在下页边距内侧；不得使用表格、普通正文段落或页脚。
存在合作（协作）单位时，其名称置于“中国电力科学研究院有限公司”下方。编写单位、每个合作（协作）单位和报告发布日期分别使用文本框中的独立段落，单倍行距、段前段后为 0，不插入空白段落或手动换行符。报告发布日期为最后一段，报告编写单位名称统一使用中文全称“中国电力科学研究院有限公司”。

除审批页明确要求“宋体加黑”外，表 B-1 只指定黑体的项目不再额外叠加粗体属性。封面表中指定为黑体的段落，其中西文和数字字体槽也统一设置为黑体，避免报告编号、系列序号和发布日期中的数字继承其他字体。英文报告名称使用 Times New Roman，并与中文名称居中排列，紧接置于中文名称正下方。若源文件未提供英文报告名称，应根据中文报告名称自动生成语义准确的英文译名，不得留空。

中文报告名称位于封面的中部偏上位置；项目来源、系列名称等可选字段为空时不得通过空段落占位，避免产生隐形垂直空白。

项目来源按实际项目填写，不要硬编码。系列报告名称和序号只在适用时显示。

未提供报告发布日期时，封面填写实际生成报告当日日期，格式为“YYYY年M月D日”；不得据此推断项目完成日期或正式出版日期。

审批页上的文字和数字使用四号宋体加粗。没有通过审批的送审稿按管理办法要求在报告名称下标注“（送审稿）”。

## 5. 摘要、关键词与目录

| 内容 | 字体字号 |
|---|---|
| “内容摘要” | 小二号黑体 |
| 中文摘要、中文关键词 | 小四号宋体，首行缩进 2 字符 |
| “ABSTRACT” | 小二号 Times New Roman |
| 英文摘要、KEYWORDS | 小四号 Times New Roman，首行缩进 2 字符 |
| “目 录” | 小二号黑体 |
| 目录内容 | 小四号宋体；英文和数字使用 Times New Roman |

- 摘要包含研究目的、方法、结果和结论，重点为结果和结论，一般不超过 500 字。为确保中英文摘要及关键词在当前模板中同页，生成时中文摘要宜控制在 200 至 320 字，英文摘要宜控制在 140 词以内。
- 关键词选取 3 至 8 个。
- 目录包含章、条、附录、参考文献及页码。
- 目录标题与第一条目录内容之间保留一行四号黑体行距；不得叠加目录命令自身的隐藏标题间距。
- 图表较多时，可在目录末尾增加图目录和表目录。

## 6. 正文

| 内容 | 字体字号 | 段落要求 |
|---|---|---|
| 一级标题 | 小三号黑体，15pt | 另起一页；段前、段后各 6pt |
| 二级标题 | 四号黑体，14pt | 段前、段后各 6pt |
| 三级标题 | 小四号黑体，12pt | 段前、段后各 6pt |
| 正文 | 小四号宋体，12pt | 1.5 倍行距，首行缩进 2 字符 |
| 图题、表题 | 五号黑体，10.5pt | 图题置于图下方居中，表题置于表上方居中；编号与题名之间空一个字符；段前段后为 0，1.5 倍行距 |
| 图注、表注、图表脚注 | 五号宋体，10.5pt | 按图表位置排版 |
| 公式 | 五号宋体，10.5pt | 公式居中，编号右对齐 |
| 表格内容 | 中文五号宋体，英文、数字五号 Times New Roman，均为 10.5pt | 1.5 倍行距；段前段后为 0；表头与表体使用同一字体字号；同一栏数字上下对齐；保持可读、避免跨页断裂 |

标题编号与标题文字之间空一个字符。

仅一级、二级、三级标题使用标题字体。`（1）`、`1）`、`①` 等更低层级编号属于正文列项，统一按正文格式处理，不加粗、不改用黑体。

列项首行缩进两个字符；列项换行后与列项正文对齐。标题后的第一个正文段落同样首行缩进两个字符；不得因为位于标题之后而取消缩进。一级标题按用户确认要求另起一页。

## 7. 图、表和公式

### 图

- 图像或图占位在上，图题紧接其下。
- 每幅图必须有编号和图题，置于图下方居中位置。
- 编号采用 `图1-1`，由章号、“-”和章内序号组成；同一章内序号从阿拉伯数字 `1` 开始连续编号。
- 编号与图题之间空一个字符。编号和图题统一使用五号黑体、1.5 倍行距，段前段后均为 0。
- 分图只允许一个层次，如 `(a)`、`(b)`、`(c)`，禁止嵌套分图。
- 每幅图必须在正文中明确提及。

### 表

- 每个表必须有编号和表题，置于表上方居中位置。
- 编号采用 `表1-1`。
- 表号和表题使用五号黑体，1.5 倍行距，段前段后均为 0；表内中文使用五号宋体，英文和阿拉伯数字使用五号 Times New Roman，1.5 倍行距，段前段后均为 0。
- 表题末行与表格顶线之间保留一个五号字 1.5 倍行距的独立间距；该间距不计入表题段前段后。
- 表内同一栏的数字应保持一致的列对齐；对于数字结果列，默认右对齐，必要时按小数点或数值边界统一对齐。
- 表题必须与表体作为一个不可拆分的排版单元；若本页剩余空间不足以容纳完整表格，应将表题和表体整体移至下一页。表格确实过长时，使用带重复表头的续表格式。
- 表前正文与表题之间保留一个正文行距的独立间距；该间距不改变正文自身的 1.5 倍行距。
- 表格结束与后续正文之间同样保留一个正文行距的独立间距；连续表格之间不得重复叠加两次该间距。
- 跨页续表应重复表头，编号写作 `表3-1（续）`。
- 表注置于表主体下方；单个表注以“注：”开头，多个表注使用“注 1：”“注 2：”连续编号。
- 表脚注置于表注下方，使用从 `a` 开始的小写拉丁字母上标标识。

### 公式

- 公式单独成行并居中。
- 编号采用 `（1-1）`，置于同一行右侧。
- 公式及编号统一使用五号宋体；变量、英文和数字可按数学排版使用 Times New Roman。
- 公式符号说明首行为“式中：”，首行缩进两个字符；后续符号说明分行排列，用破折号连接符号与释文。

## 8. 附录

- 每个附录另起一页。
- 首行为附录编号和标题，例如 `附录 A 标题名称`，小三号黑体、居中。
- 附录编号从大写拉丁字母 `A` 开始。
- 附录内标题使用 `A1`、`A1.1` 等编号。
- 附录内图、表、公式使用 `图A-1`、`表A-1`、`（A-1）` 等编号。
- 附录正文使用小四号宋体，格式与正文一致。

## 9. 参考文献

- 参考文献为可选部分；存在引用时必须生成。
- 另起一页，位于最后一个附录之后。
- 标题“参考文献”使用小三号黑体并居中。
- 条目使用小四号宋体。
- 每条空两个汉字起排，回行顶格。
- 文献编号置于方括号内，从 `[1]` 开始，编号与著录项之间空一个字符。
- 每条文献末尾不加标点符号。
- 著录项目按来源文件附录 B 表 B-2；未覆盖的类型采用适用的现行国家标准格式，但仍遵守本节版式要求。

## 10. 生成后检查

每次生成后必须同时执行结构检查和视觉检查：

1. 检查页面尺寸、页边距、页眉页脚距离和分节页码。
2. 检查封面、审批页、摘要页、目录、正文首页、附录和参考文献的顺序。
3. 检查标题、正文、图表、公式和参考文献的字体字号。
4. 检查摘要不超过 500 字，关键词数量为 3 至 8 个；封面日期为空时核对其是否已填写生成报告当日日期。
5. 检查图、表、公式和附录编号连续且格式正确。
6. 检查文档中没有残留 `{{PLACEHOLDER}}` 或图表测试占位文本。
7. 将 DOCX 渲染为 PDF，逐页检查重叠、截断、异常空白页、页码和分页。
