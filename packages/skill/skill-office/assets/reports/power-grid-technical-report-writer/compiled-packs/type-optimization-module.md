# 创新模块或优化方法章节

适用于解决局部瓶颈的新增模块。章节先以无标题章首导入正文完成背景、研究主题和概括性技术路线，随后X.1—X.3说明模块结构、输入输出、具体技术作用、实现和独立贡献证据。

公式默认`must`，应明确优化变量、目标/损失、约束或更新关系。不存在真实数学关系时调整需求级别，不写任意加权和。

应通过去除、替换或组合消融说明模块贡献，并分析复杂度、代价、适用条件和失败模式；这些证据默认嵌入对应研究小点，只有 `evaluation-related` 主题且存在大量成体系数据或用户明确要求时才可单设评估/验证二级节；`non-evaluation` 主题不得设置验证、评估、测试、试验、实验类二三级标题。

公式选择沿用全局规则：描述性公式从简，技术公式从充分。能够用文字清楚说明的简单关系不为形式感单列；本章真实存在的原理、损失、目标、约束、更新、推断、评分或关键性能关系应完整表达并解释。
