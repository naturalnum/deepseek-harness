# 集成验证或工程应用章节

适用于多项成果的联合运行和工程应用。章节先以无标题章首导入正文完成工程背景、研究主题和总体技术架构/路线概括，再由X.1—X.3说明集成接口、数据/控制链路、部署环境、运行证据、故障与边界。默认不单设应用验证二级节；`non-evaluation` 主题的二三级目录禁止验证/评估/测试/试验/实验类章节词；只有 `evaluation-related` 主题且存在大量成体系数据或用户明确要求时才可例外。

公式通常为`should`，仅用于综合性能、可靠性、资源利用、时延或评价指标。重点回答组合后是否仍有效、是否产生新瓶颈以及是否满足真实电网运行条件。

公式选择沿用全局规则：描述性公式从简，技术公式从充分。能够用文字清楚说明的简单关系不为形式感单列；本章真实存在的原理、损失、目标、约束、更新、推断、评分或关键性能关系应完整表达并解释。
