# 单项技术、模型或算法章节

适用于预测、辨识、估计、优化、控制和推理方法。章节先以无标题章首导入正文完成背景、研究主题和概括性技术路线，随后X.1—X.3将问题形式化、核心模型、求解或训练及应用作用归并为三个章内研究小点，默认在X.3后直接进入本章小结。

公式默认`must`，但只保留问题定义、物理/模型关系、目标函数、约束、更新规则和实际评价指标。符号对应电网对象时直接按节点电压、支路功率、设备温度等定义。

与核心主张相关的对比、消融、敏感性、鲁棒性或失败案例应优先嵌入相应X.1—X.3正文。`non-evaluation` 主题不得以验证、评估、测试、实验等词设置二三级标题；只有 `evaluation-related` 主题且数据量大、分析体系独立或用户明确要求时，才单设评估/验证二级节。

公式选择沿用全局规则：描述性公式从简，技术公式从充分。能够用文字清楚说明的简单关系不为形式感单列；本章真实存在的原理、损失、目标、约束、更新、推断、评分或关键性能关系应完整表达并解释。
