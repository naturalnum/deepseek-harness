# 中国电科院技术报告格式规范

本规范提取自用户提供的《技术报告格式.pdf》附录 B“技术报告格式”和附录 C“技术报告模板”。生成报告时以本文件为格式依据，以 [`../assets/report.docx`](../assets/report.docx) 为版式载体；两者不一致时，先按本文件修正模板和生成结果。用户已明确要求正文一级标题另起一页。

## 1. 报告构成

按以下顺序组织报告：

1. 封面
2. 审批页
3. 中文摘要、中文关键词、英文摘要、英文关键词
4. 目录
5. 正文
6. 附录（可选）
7. 参考文献（可选）

中文摘要、中文关键词、英文摘要和英文关键词按既定顺序排版，可根据实际内容长度自然分页。附录置于正文之后、参考文献之前。

## 2. 页面设置

| 项目 | 要求 |
|---|---|
| 纸张 | A4，210mm x 297mm，纵向 |
| 上边距 | 30mm |
| 下边距 | 25mm |
| 左边距 | 25mm |
| 右边距 | 25mm |
| 页眉 | 可选；仅从正文第一页开始 |
| 页眉内容 | 技术报告中文名称，五号宋体，居中，与正文之间用下划线分隔 |
| 页眉位置 | 距上边界 25mm |
| 页脚位置 | 距下边界 15mm，无分隔线 |

封面至目录页不设置页眉。封面和审批页不设置页脚。

## 3. 页码与分节

- 中文摘要与关键词页开始设置页脚，使用小写罗马数字 `i, ii, iii...`。
- 目录延续前置部分的小写罗马数字页码。
- 正文第一页改用阿拉伯数字并从 `1` 重新编号。
- 正文、附录和参考文献使用连续的阿拉伯数字页码。
- 页码使用五号宋体，可居中或置于外侧；本 skill 统一采用居中。

## 4. 封面与审批页

封面按以下位置和样式排版：

| 内容 | 字体字号 |
|---|---|
| 报告编号、分类号、密级 | 五号黑体 |
| 项目来源 | 小三号黑体 |
| 中文报告名称 | 小二号黑体 |
| 英文报告名称 | 与模板保持一致，使用 Times New Roman |
| 系列报告名称及序号 | 小三号黑体 |
| 中国电力科学研究院有限公司 | 四号黑体 |
| 合作（协作）单位 | 四号黑体 |
| 报告发布日期 | 四号黑体 |

报告编号、分类号、密级三行位于封面右上方，使用同一个左起点左对齐；区块宽度按三行实际内容动态计算，最长一行（通常为报告编号）的最右字符贴齐右页边距内侧，即正文版心右边缘。
报告编写单位、合作（协作）单位和报告发布日期作为一个连续区块置于封面底部，并在正文宽度内居中。该区块使用封面正文层中的无边框浮动文本框，文本框底端固定在下页边距内侧；不得使用表格、普通正文段落或页脚。
存在合作（协作）单位时，其名称置于“中国电力科学研究院有限公司”下方。编写单位、每个合作（协作）单位和报告发布日期分别使用文本框中的独立段落，单倍行距、段前段后为 0，不插入空白段落或手动换行符。报告发布日期为最后一段，报告编写单位名称统一使用中文全称“中国电力科学研究院有限公司”。

除审批页明确要求“宋体加黑”外，表 B-1 只指定黑体的项目不再额外叠加粗体属性。封面表中指定为黑体的段落，其中西文和数字字体槽也统一设置为黑体，避免报告编号、系列序号和发布日期中的数字继承其他字体。英文报告名称使用 Times New Roman，并与中文名称居中排列。

项目来源按实际项目填写，不要硬编码。系列报告名称和序号只在适用时显示。

审批页上的文字和数字使用四号宋体加粗。**仅此审批页**中的两字中文人名在两个字之间加入一个半角空格，例如“张三”排为“张 三”；三字及以上中文姓名不插入空格。该规则不得扩展到封面、摘要、正文、附录、参考文献或其他页面。没有通过审批的送审稿按管理办法要求在报告名称下标注“（送审稿）”。

## 5. 摘要、关键词与目录

| 内容 | 字体字号 |
|---|---|
| “内容摘要” | 小二号黑体 |
| 中文摘要、中文关键词 | 小四号宋体 |
| “ABSTRACT” | 小二号 Times New Roman |
| 英文摘要、KEYWORDS | 小四号 Times New Roman |
| “目 录” | 小二号黑体 |
| 目录内容 | 小四号宋体；英文和数字使用 Times New Roman |

- 摘要不设置字数、词数、段落数、句数、写作人称、必含内容要素或中英文逐项对应等内容约束；按上游提供或已确认的摘要内容直接排版。
- 关键词不设置数量限制；仅保持中文与英文关键词各自的版式和分隔符规范。
- 目录包含章、条、附录、参考文献及页码。
- **主目录后必须继续设置图、表动态目录域**；即使当前报告图或表较少，也保留对应目录域，便于后续更新。
- 图、表条目字体、字号、行距、点引导线、制表位和页码对齐方式全部直接沿用主目录条目格式；**不得显示“图目录”“表目录”独立标题，也不得在主目录条目与图条目、图条目与表条目之间人为插入空行。**
- 图动态目录域仅收集真正独占一段的“图X-X 图题”，表动态目录域仅收集真正独占一段的“表X-X 表题”；图号/表号与题名之间必须有明确空格。正文说明段即使提到具体图表，也不得写成“图1-1应表达……”“表2-1给出……”这类编号起句，而应改为“该图应表达……”“该表给出……”“上述趋势/上述结果……”等自然说明。
- “内容摘要”“ABSTRACT”标题必须各保留一个隐藏 `TC ... \\f C \\l "1"` 标记；图题、表题分别写入 `\\f F`、`\\f T` 隐藏 TC 域，非图题/表题段落禁止写入 F/T TC 域。
- 最终 DOCX 保存后优先调用 Microsoft Word 自动更新全部字段和三个 TOC 域（主目录、图条目、表条目），并保存更新后的缓存结果；同时保留 `w:updateFields=true` 与 dirty field 作为后续再次打开 Word 时的兜底。视觉验收不得出现“未找到目录项”类提示，且存在图题/表题时必须看到对应图条目/表条目。

## 6. 正文

| 内容 | 字体字号 | 段落要求 |
|---|---|---|
| 一级标题 | 小三号黑体，15pt | 另起一页；段前、段后各 6pt |
| 二级标题 | 四号黑体，14pt | 段前、段后各 6pt |
| 三级标题 | 小四号黑体，12pt | 段前、段后各 6pt |
| 正文 | 小四号宋体，12pt | 1.5 倍行距，通常首行缩进 2 字符；独立公式后的首个文字段落首行不缩进 |

正文中的普通文本符号实行末端确定性归一化：中文标点和全角符号使用宋体字体槽，英文、数字及常用技术符号使用 Times New Roman 字体槽，字号与所在正文一致为 12pt；清除源 HTML、模板或转换器遗留的 theme/hint 字体属性，避免 `（ ）`、`%`、`±`、`×`、`℃`、`≤`、`≥`、希腊字母等在同一段中出现字体或字号跳变。OMML 数学公式、上下标和上标引用保持其数学/引用语义格式，不进行普通文本归一化。
| 图题、表题 | 五号黑体，10.5pt | 居中 |
| 图注、表注、图表脚注 | 五号宋体，10.5pt | 按图表位置排版 |
| 公式 | 五号宋体，10.5pt | 公式居中，编号右对齐 |
| 表格内容 | 五号宋体，10.5pt | 保持可读、避免跨页断裂 |

标题编号与标题文字之间空一个字符。

仅一级、二级、三级标题使用标题字体。`（1）`、`1）`、`①` 等更低层级编号属于正文列项，统一按正文格式处理，不加粗、不改用黑体。

列项首行缩进两个字符；列项换行后与列项正文对齐。一级标题按用户确认要求另起一页。

## 7. 图、表和公式

### 图

- 图像或图占位在上，图题紧接其下。报告生成链中的图占位统一渲染为白底、黑色细边框、无文字的矩形白框；不得保留“【此处插入图X-X】”文字到最终 Word。
- 每幅图必须有编号和图题，置于图下方居中位置。
- 编号采用 `图1-1`，由章号、连字符和章内序号组成。
- 分图只使用一个层次，如 `(a)`、`(b)`、`(c)`，每个分图均有标题。
- 每幅图必须在正文中明确提及。

### 表

- 每个表必须有编号和表题，置于表上方居中位置。
- 编号采用 `表1-1`。
- 跨页续表应重复表头，编号写作 `表3-1（续）`。
- 表注置于表主体下方；单个表注以“注：”开头，多个表注使用“注 1：”“注 2：”连续编号。
- 表脚注置于表注下方，使用从 `a` 开始的小写拉丁字母上标标识。

### 公式

- Markdown/HTML 源中的 `$...$`、`\(...\)`、`$$...$$`、`\[...\]` 只是输入格式；进入 Word 时必须确定性转换为 Word 原生 OMML 数学对象，禁止把 LaTeX 源码作为普通可见文本排版。
- 行内公式保持嵌入所在段落；独立公式单独成行并居中。未编号显示公式也必须输出为原生 OMML。
- 编号采用 `（1-1）`，置于同一行右侧；Markdown 中的 `\tag{1-1}` 在转换时拆为右侧编号，不保留 `\tag` 文本。
- 公式及编号统一使用五号宋体；变量、英文和数字可按数学排版使用 Times New Roman。
- 独立公式后的第一个实际文字段落首行不缩进；若该段为“式中：”符号说明，同样首行不缩进。后续符号说明分行排列，用破折号连接符号与释文。
- 最终 DOCX 的正文、表格单元格等可见文本中不得残留 `$`/`$$` 数学定界符、`\frac`/`\sum`/`\sqrt` 等 LaTeX 数学命令、`x_{i}`/`x^{2}` 等裸露脚本写法，或 `[[TECH_REPORT_*MATH_B64:...]]` 内部标记。发现任一残留必须判定结构校验失败。

## 8. 附录

- 每个附录另起一页。
- 首行为附录编号和标题，例如 `附录 A 标题名称`，小三号黑体、居中。
- 附录编号从大写拉丁字母 `A` 开始。
- 附录内标题使用 `A1`、`A1.1` 等编号。
- 附录内图、表、公式使用 `图A-1`、`表A-1`、`（A-1）` 等编号。
- 附录正文使用小四号宋体，格式与正文一致。

## 9. 参考文献

- 参考文献为可选部分；存在引用时必须生成。
- 另起一页，位于最后一个附录之后。
- 标题“参考文献”使用小三号黑体并居中。
- 条目使用小四号宋体。
- 每条空两个汉字起排，回行顶格。
- 文献编号置于方括号内，从 `[1]` 开始，编号与著录项之间空一个字符。
- 全部正式参考文献统一采用 **GB/T 7714—2015《信息与文献 参考文献著录规则》顺序编码制**。
- 每条文献必须包含与来源类型一致的文献类型标识，例如 `[J]`、`[M]`、`[C]`、`[D]`、`[R]`、`[S]`、`[P]`、`[EB/OL]`、`[DB/OL]`。
- 条目著录项目和标点按 GB/T 7714—2015 组织，条目以句点 `.` 结束。
- 不得在同一报告中混用 APA、MLA、Chicago、IEEE bibliography 等其他文后样式。
- 著录项目缺失时不得补造，必须使用已核验元数据补齐或返回内容生成环节处理来源缺口。

## 10. 生成后检查

每次生成后必须同时执行结构检查和视觉检查：

1. 检查页面尺寸、页边距、页眉页脚距离和分节页码。
2. 检查封面、审批页、摘要页、目录、正文首页、附录和参考文献的顺序。
3. 检查标题、正文、图表、公式和参考文献的字体字号；额外检查正文段内普通符号是否与所在段落保持统一字体槽、字号和非强调属性。
4. 检查摘要与关键词的标题、字体、顺序、分隔符和页码等版式要求；不检查摘要篇幅、内容结构或关键词数量。
5. 检查图、表、公式和附录编号连续且格式正确；同时确认公式已转换为 Word 原生 OMML，正文和表格可见文本中不存在原始 LaTeX 或内部公式标记。
6. 检查文档中没有残留 `{{PLACEHOLDER}}` 或图表测试占位文本。
7. 将 DOCX 渲染为 PDF，逐页检查重叠、截断、异常空白页、页码和分页。
