# 公开评审依据与链接

检索日期：2026-09-02。外部资料用于形成通用评审维度，不替代具体项目任务书。

1. [GB/T 7713.3-2014《科技报告编写规则》国家标准信息页](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=E2BA32B0F5E570E5844A9E7E2D42393F)
   - 国家标准信息页显示该标准现行，可用于报告构成、编排与著录规范的检查。
2. [国家科技报告服务系统：科技报告知识问答](https://www.nstrs.cn/kjbg/static/jump?type=artileDetails)
   - 明确科技报告应完整描述理论、假设、过程、方法和结果，提供必要图表数据；呈交前应开展格式、内容和密级审查，内容审查关注清晰、系统、完整、可读以及试验条件、设备、数据和结果分析。
3. [中国政府网：国家科技计划项目评估评审行为准则与督查办法](https://www.gov.cn/zhengce/2003-01/29/content_5711093.htm)
   - 用于约束独立、客观、公正、回避、保密和如实反映专家意见，不据此推导具体技术指标。
4. [NIST AI RMF Core - Measure](https://airc.nist.gov/airmf-resources/airmf/5-sec-core/)
   - 用于人工智能报告的测试、评价、验证与确认维度：测试集、指标、工具、部署条件、有效性、可靠性、安全性、透明度及局限性应有文档化证据；独立评审有助于降低内部偏差。
5. [NIST AI RMF 1.0](https://www.nist.gov/publications/artificial-intelligence-risk-management-framework-ai-rmf-10)
   - 用于补充人工智能系统的可信性评审维度，包括有效可靠、安全、韧性、透明、可解释、隐私和公平。
6. [NIST Generative AI Profile](https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.600-1.pdf)
   - 仅在报告涉及生成式人工智能时使用，重点检查数据来源、测评、风险记录和适用范围；不得把自愿性框架写成本项目强制验收条款。

## 使用要求

- 正式意见若引用外部准则，应说明其是“通用审查参考”，除非任务书或管理办法明确将其列为强制依据。
- 联网内容可能更新；每次实际使用时应核验链接仍有效、版本仍适用，并记录访问日期。
- 不采用无作者、无机构、营销软文、论坛帖子或无法追溯来源的“常见审稿意见模板”。
