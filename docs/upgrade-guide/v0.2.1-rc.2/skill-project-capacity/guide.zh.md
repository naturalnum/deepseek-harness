# 技能项目容量读取方须支持空无记录目录

[English](guide.md) | 中文

## 变更

启用 `pe-cloud-files/root.skillProjection` 时，`maxProjects` 继续限制持久技能副本关联。达到上限后，只执行命令的工作区可使用空 `.pe/skills` 目录执行，不再向私有 `skill-working-copies/` 添加记录。每次操作都重新核空；物化技能仍须有持久关联。不删除数据，也不提高配置上限。旧读取方会把无记录目录归为不确定写入失败，可能在该进程中拒绝账号的所有后续写入。

## 迁移

1. 同时升级 `pe-cloud-files` 和 `pe-opensandbox`。保留原 `skillProjection` 限额和已核实的存储设置，保留关联记录和工作副本。
2. 验证已满关联的账号可在额外工作区执行命令，且不能超额发布技能关联。验证非空无记录目录被拒绝但不封锁账号的其他写入；不确定写入结果仍须保留责任。
3. 首次创建无记录目录后，回退版本须保留兼容读取方。不得降回不支持空目录的读取方、删除关联记录或修改存储状态绕过上限。确须如此降级时，先停止并另行评审离线迁移，仅验证和删除空的无关联目录；本版本不提供自动降级转换。
