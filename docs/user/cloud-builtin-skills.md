# Cloud built-in skills

English | [中文](cloud-builtin-skills.zh.md)

This operator reference describes the trusted Cloud account recipe, not personal skill installation. The [example overlay](../../apps/cli/config/examples/cloud-builtin-skills.cordis.yml) registers seven Office skills and six report skills through the native providers. Native precedence permits an installed same-name skill to override a built-in; the management page retains both rows and exposes immutable built-in details, files and complete package downloads.

Prepare a versioned release directory outside tenant writable storage. Copy `packages/skill/skill-office/assets` and `packages/skill/skill-office/assets/reports` there, retaining sibling directories and the generated package carriers. Run `python3 scripts/package-builtin-skills.py --check`. Preserve the supplied report asset permissions and [source notice](../../packages/skill/skill-office/assets/reports/SOURCES.json); internal integration does not imply an additional redistribution license.

Build the guest with [the Office dependency Dockerfile](../../packages/cloud/pe-opensandbox/runtime/office/Dockerfile), selecting the exact approved base image. Native LibreOffice, including its Math component for Word equations, and Poppler supply operations without changing the default execution limits. The image explicitly installs `poppler-data`: it is a recommended dependency omitted by `--no-install-recommends`, and its CMaps are required for the supplied Chinese PDF sample. The font preparation extracts complete Simplified Chinese faces and verifies glyph and Unicode mapping preservation; the image retains the original font licenses. Export that image's `/opt/dsh/runtime/runtime.json` into a protected Host carrier directory and bind its digest to the same release/image. Set `DSH_BUNDLED_OFFICE_SKILLS`, `DSH_BUNDLED_REPORT_SKILLS` and `DSH_EXECUTION_RUNTIME_MANIFEST` to those absolute Host directories before applying the overlay to the account recipe and running its normal sealing/audit. Guest paths in the overlay remain guest paths; never replace them with Host interpreter paths.

The Linux [Word catalog operation](../../packages/cloud/pe-opensandbox/runtime/office/refresh_word.py) supports the bundled report main, figure and table `TOC \f C/F/T` fields in that order, including outline levels 1–3 and matching TC marks. It rejects other catalog structures. It asks a private native Writer instance to calculate page references in disposable working copies, then copies only cached entries and link bookmarks into the original DOCX. Original field codes, non-catalog body/sections and other ZIP member bytes are retained; input macros and external-link updates are disabled. The original resources, including the Windows COM script, remain unchanged. The example recipe supplies report guidance through the native filesystem provider and optional `systemTools.wordRefresh`; native skill results persist that guidance.

Run `/opt/dsh/runtime/office/refresh_word.py <source.docx> <new-output-directory> --soffice /usr/bin/soffice --timeout-seconds <remaining-execution-seconds> --cancel-grace-seconds <remaining-cancellation-seconds>` inside the existing managed Bash execution. Select explicit finite timing within its current limits. Existing output paths reject. Success publishes `report.docx`, `report.pdf` and `catalogs.json`; ordinary failure or confirmed cancellation removes its own partial files. Unconfirmed child quiescence retains private working files and fails, leaving responsibility with the original execution owner. Inspect the delivered PDF and compare cached references with printed page labels; exit status and stored fields alone do not establish layout quality.

Qualify the resulting image and actual account recipe under the existing permissions, approval, CPU, memory, process, disk and execution budgets. Verify skill loading, generated and modified DOCX/PPTX/XLSX, formula caches, rendered pages, Chinese fonts, PDF/Word reports, previews/downloads and cancellation. The [Word equation probe](../../packages/cloud/pe-opensandbox/tests/builtin-word-math-guest-probe.py) requires visible equation text in the rendered PDF; stored XML alone does not verify equation rendering. Dependency preparation, returned interpreter paths, unit tests and a disposable CLI probe do not establish deployed account or real-model acceptance. Keep failed cases and output hashes in the release evidence, and retain the previous release until the original runtime owner completes normal deployment and acceptance.

The [Chinese PDF probe](../../packages/cloud/pe-opensandbox/tests/builtin-pdf-cmap-guest-probe.py) requires expected Chinese text from the selected Poppler executable and verifies the input digest remains unchanged; a zero extraction exit alone is insufficient. Native Bash clears the image environment and supplies its own execution variables. Qualify font selection and all operations through that actual command environment; Dockerfile environment values and standalone CLI results do not establish Native Session behavior.
