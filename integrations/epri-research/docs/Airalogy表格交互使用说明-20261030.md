# Airalogy 表格交互使用说明

更新：2026-10-30。适用于当前单机版 DeepScientist 科研工作台。

现在可以在实验表格里填写输入，自动校验、运行协议计算、回填结果、更新图表并保存草稿。计算使用现有 Airalogy Docker 引擎；需要先为协议接好计算规则。普通表格不会自动生成实验结论，这个入口也不会自动控制真实设备。

## 日常使用

右侧导航选择“实验与结果”。页面先显示“下一步”和“最近实验”：每条实验显示最近保存的计算指标，点击“继续填写”恢复原记录，已提交的记录点击“查看结果”。下方“开始新实验”用于创建独立记录。方法版本、源码、JSON 单次操作和逐次执行历史默认折叠，维护时展开“方法说明与版本”或“高级配置与执行记录”。表格页顶部显示“本次计算结果”和下一步提示；自动计算正常时无需再点击保存草稿。

## 先体验设备数据质量示例

1. 保持 Docker Desktop 运行，打开 Harness，选择“科学研究 · DeepScientist”。
2. 点击对话上方科研工作台的“在右侧展开”，在右侧进入“实验与结果”。
3. 没有实验方法时，点击“载入设备数据质量示例”；已有其他方法时可从“高级配置与执行记录”载入。打开源码审阅页，检查本地示例的协议和 Python 计算代码，填写审阅意见并批准该版本。
4. 点击该协议包的“打开交互实验表”，然后点击“开始运行”。表格和计算都在当前网页的右侧，不用跳转到其他端口。
5. 在表格增加一行，填写测点名称、应有采样点 `1000`、有效采样点 `950`。停止输入约 650 毫秒后，系统计算并保存，缺失率显示 `5`，对应图表同步更新。
6. 把有效采样点改为 `980`，缺失率变为 `2`。再加一行 `1000 / 900`，第二行缺失率为 `10`，两行总体缺失率为 `6`。
7. 如果有效点填成 `1100`，系统显示校验原因，清除失效结果。修正后重新计算。右上方显示“已计算并自动保存”后，输入、结果和计算来源已一起保存。
8. 完成核对并勾选复核项，再完成运行/提交。修改输入会清除先前的人工复核，不能沿用旧确认。

同一个已批准版本只需完成一次源码审阅，之后改表格不必重新输入 JSON 或重复批准。更换计算源码需要发布、审阅新版本。

如果提示“自动计算环境尚未就绪”，启动 Docker Desktop，等待 Linux 引擎就绪后，再点“打开交互实验表”；无需重新导入或重新审批协议。2026-10-30 已修复首次执行失败后重试、多页签状态滞后导致的 `Protocol versions are immutable` 误报：打开表格会读取服务器最新协议，并在源码完全一致时复用同一版本；源码不同仍须使用新版本，不覆盖历史记录。

## 用在自己的协议上

已有计算包可直接导入“实验与结果”，完成审阅后打开交互实验表。已有草稿可在记录页展开“为这条记录连接自动计算”，选择已批准的协议包并绑定。计算包中的 `protocol.aimd` 必须和该记录的协议源码完全相同。

协议包至少包含：

| 文件 | 作用 |
| --- | --- |
| `protocol.aimd` | 定义表格、输入字段、输出字段和人工核对项 |
| `protocol.toml` | 协议标识和版本 |
| `assigner.py` | Airalogy 自动计算规则，交互计算仅执行 `mode="auto"` 的规则 |
| `interaction.json`（可选） | 定义从表格哪些列生成图表 |

输入通常使用 `owner="human"`。自动计算的输出必须使用 `owner="system"` 或 `owner="agent"`，在表格内只读。逐行规则可以引用 `measurements.expected` 等列；整表汇总规则依赖 `measurements`。跨表计算需写成整表计算规则。

示例源码在 `examples/interactive-power/`。图表声明示例：

```json
{"charts":[{"id":"missing-rate","title":"各测点缺失率（%）","table":"measurements","label":"channel","value":"missing_rate"}]}
```

没有图表声明的包仍可自动校验、计算和回填数值。计算规则和图表声明属于被审阅的同一个源码版本。

## 保存、复核和交换

- 表格修改会自动保存并计算；计算中可以继续修改输入，系统会按最新输入重新计算，较早结果不会覆盖新输入。
- 输入缺失或计算失败会清除对应的旧结果，并在“计算依据与校验详情”显示原因。未算完、有错误或结果与输入不匹配时不能正式提交。
- “计算依据与校验详情”保存协议包版本、源码指纹、运行来源以及校验结果。重新打开已经保存的记录不会无故重新执行；“再次运行”会沿用计算绑定，创建独立记录。
- `.aira` 导出包含输入、结果、来源和所绑定计算包的源文件。导入后保留历史结果，但不会自动批准或执行其中代码；再次执行前须将源包导入、审阅并重新绑定。
- 单次交互计算最多等待 45 秒，超时会停止该次运行，页面明确提示输入尚未保存。长任务应使用现有协议执行页，或缩小单次表格数据量。
