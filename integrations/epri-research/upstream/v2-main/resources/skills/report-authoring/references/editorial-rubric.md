# Editorial Rubric

Use this as a short warning pass before publication. It is advisory: a missing
optional module should produce a note or a Partial Report, not a dead end.

Score each item 0 (missing), 1 (usable), or 2 (clear):

1. The first paragraph answers the user's actual question.
2. Scope, period/as-of, units and comparator are easy to find.
3. The main result is separated from interpretation and hypothesis.
4. The lead visual or metric block has a distinct reader job and a takeaway.
5. The report uses only sections with material content.
6. Uncertainty, missing data and the condition that would change the answer are
   stated in plain language.
7. The next useful action is concrete and conditional.
8. Sources and methods are available without taking over the first viewport.

Repair the lowest scoring item once. Do not add decorative charts, repeat the
same result in three formats, or restart a long provider workflow just to raise
the score. If evidence is genuinely insufficient, narrow the conclusion and
label the report partial or blocked according to the active contract.
