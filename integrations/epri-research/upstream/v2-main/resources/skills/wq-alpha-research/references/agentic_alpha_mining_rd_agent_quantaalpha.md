# Agent 化 Alpha 挖掘：AlphaAgent / RD-Agent / QuantaAlpha

用于高级自动因子挖掘。默认不运行重型框架，只提炼可复用 SOP。

## 1. 适用场景

- 用户明确希望 Agent 连续提出、执行、评估和迭代因子。
- 有可用数据环境、回测环境和计算预算。
- 可以接受较长运行时间和多轮失败。

## 2. 建议的轨迹式循环

1. **Research Direction**：确定市场、资产、数据源和机制族。
2. **Planning**：生成 3-5 个机制差异明显的候选方向；先检查结构原创性、假设与表达式对齐、复杂度和字段可用性。
3. **Implementation**：写最小可运行脚本或平台表达式。
4. **Evaluation**：只记录真实运行结果。
5. **Diagnosis**：失败原因归类为数据、表达式、泄漏、换手、容量、相关性、样本外。
6. **Mutation**：只改一个主要假设或机制，不做无意义窗口堆叠。
7. **Promotion**：通过硬门控并证明对现有组合有边际价值后，才进入下一阶段。

这些步骤是连续研究的建议结构。普通探索或单因子诊断不需要完整执行，也不需要为了模仿开源框架启动多个 Agent。

## 3. 门控建议

- idea-only：可解释且字段可获得。
- locally checked：无明显泄漏，静态检查通过。
- backtested：有真实 IC/收益/换手/成本结果。
- robust：跨区间、行业、市值、市场阶段稳定。
- deployable：容量、交易成本、监控和失效处理明确。

## 4. 报告要求

每轮输出：

- 本轮候选和机制。
- 实际运行了什么。
- 指标和失败原因。
- 下轮保留、修改、放弃的路线。
