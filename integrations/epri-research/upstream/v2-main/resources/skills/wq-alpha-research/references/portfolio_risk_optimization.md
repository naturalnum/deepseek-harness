# 组合构建与风险优化

用于因子通过初步验证后，把信号变成组合或风险报告。不要在因子有效性未确认前过早优化组合。

## 1. PyPortfolioOpt

适合常规组合优化：

- 均值方差。
- 最大 Sharpe。
- 最小波动。
- Black-Litterman。
- HRP。

## 2. Riskfolio-Lib

适合高级风险：

- CVaR、CDaR、EVaR 等风险度量。
- 风险预算和风险平价。
- 复杂约束。
- 因子风险贡献。

## 3. SOP

1. 先确认 alpha 或预期收益来源。
2. 明确协方差估计窗口、频率和 shrinkage。
3. 写清约束：单资产上限、行业上限、换手、杠杆、做空、交易成本。
4. 输出权重前后都要看集中度、回撤、换手和敏感性。

## 4. 输出建议

- 权重表。
- 风险贡献表。
- 与基准比较。
- 对估计误差和约束变化的敏感性说明。
