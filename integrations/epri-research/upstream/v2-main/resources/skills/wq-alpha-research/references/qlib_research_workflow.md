# Qlib 研究流水线

Qlib 适合完整项目级量化研究：数据处理、特征、模型训练、回测、报告。它不是轻量默认依赖，只有当用户需要完整流水线时再建议使用。

## 1. 适用场景

- 用户有本地行情和因子数据，希望建立可复现研究项目。
- 需要 Alpha158/Alpha360、LightGBM、模型训练、回测和报告。
- 需要从单因子走向多因子/模型组合。

## 2. 标准步骤

1. 准备数据目录和交易日历。
2. 配置股票池、训练/验证/测试区间。
3. 选择特征模板或自定义因子。
4. 运行模型训练和预测。
5. 回测策略，输出 risk analysis 和 report。
6. 记录配置文件、数据版本和输出路径。

典型入口：

```bash
qrun examples/benchmarks/LightGBM/workflow_config_lightgbm_Alpha158.yaml
```

## 3. 注意

- 官方样例数据可能不可直接下载；优先使用用户自有数据。
- 不要把 Qlib 报告等同于生产策略，仍需要成本、容量和样本外检查。
- 若用户只要单因子验证，Alphalens 通常更轻。
