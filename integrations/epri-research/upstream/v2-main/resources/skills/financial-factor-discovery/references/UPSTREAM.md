# Upstream provenance

Source: https://github.com/uwFengyuan/XAlpha_Prompt

The upstream repository did not contain a license file when this snapshot was taken. Keep this snapshot isolated as provenance material and review redistribution terms before a public release. DeepScientist runtime prompts should prefer the adapted contracts in this Skill unless an approved upstream prompt is explicitly selected.
