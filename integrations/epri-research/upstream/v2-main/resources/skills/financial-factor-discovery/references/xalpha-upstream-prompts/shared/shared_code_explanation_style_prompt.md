# Shared Code Explanation Style Prompt

Prompt constant: `SHARED_CODE_EXPLANATION_STYLE_PROMPT`

Placeholders: None

````text
### Code Explanation Style

Generated code should be readable as a compact research artifact.

Docstring/comments:
- Describe only the implemented mechanism.
- Keep the docstring concise.
- Do not overclaim predictive power.
- Do not introduce mechanisms, inputs, filters, regimes, or formulas absent from the code.
- Use comments only for important computation steps, not for restating Python syntax.

Readability:
- Use descriptive variable names.
- Expose important intermediate computations when helpful.
- Avoid one opaque final expression.
````
